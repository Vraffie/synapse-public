# Mock child process identity and group stop

This Linux-only primitive is not wired into the daemon. `capture_mock_child` records a session-leading child PID, Linux `/proc` start ticks, boot ID and supervisor PID/start ticks. `inspect_mock_child` returns `UNKNOWN` if the original supervisor is not the current process, the boot or PID start time differs, the child is missing, is no longer the supervisor's child/session leader, or proc access fails. A restarted supervisor must reconcile unknown work; it cannot signal a PID using a stale record.

`stop_mock_child_group` accepts only the original unreaped `Popen` handle and matching current identity. It requires the default SIGCHLD disposition and exclusive reaping: no other thread or handler may poll, wait or call `waitpid` for that child. Under this caller obligation, the child PID remains reserved through final identity checks and TERM/KILL escalation, even if it becomes a zombie. Ambiguous observations or signaling permission errors return `UNKNOWN`; do not retry or claim cleanup based on an unknown result. A `SIGNALLED_GROUP` result confirms signaling the original group and reaping its leader, not that all descendants have exited or that descendants which escaped into other sessions were terminated. Network/process sandboxing, cgroups, durable recording, worker fencing after a daemon crash, real CLI/provider credentials and API wiring remain separate, unimplemented work. Never pass untrusted identity records or an arbitrary process as proof of ownership.
