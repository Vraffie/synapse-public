# In-process message gateway

`MessageGateway` accepts a session bearer secret, an operation name and bounded raw JSON bytes. It derives the principal from the secret and invokes the scoped message service; request-supplied principal, run and sender fields are rejected. Supported operations are send, claim, read and complete. JSON object keys must be unique and numbers finite. The authority's revocation lock spans authentication and the synchronous service call: a revocation from another thread waits for an in-flight call and blocks later calls.

The adapter does not start a server or implement MCP. Trusted code must create the session authority, provision exact resource grants and a daemon-owned SQLite connection, and keep the authority and raw service inaccessible to agents. The connection must be used according to SQLite thread ownership; a thread lock does not make a connection cross-thread safe. A future transport must bound request bytes before buffering, protect bearer secrets, translate exceptions without leaking secrets, and apply its own connection and resource limits. Same-user processes with memory or environment access can still steal bearer secrets. A revocation initiated reentrantly by trusted code in the same thread is not a concurrent revocation barrier.

Trusted daemon code can call `grant_owned_delivery(principal, delivery_id)` to add read and completion permissions to the existing session without changing its principal or credential. It requires that the session's instance belongs to its run, owns the delivery in that run, and already has inbox-claim and thread-access grants. It does not grant artifact access; existing artifact policy still applies. The session's total grants remain bounded, and grant addition and revocation use the same lock. This is a trusted provisioning method, not an agent operation: do not expose it or the authority object across an untrusted boundary. SQLite connection thread ownership still applies. Session expiry and persistent credential storage remain unimplemented.
