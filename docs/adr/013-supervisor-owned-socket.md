# ADR 013: Optional supervisor-owned Unix listener

Status: implemented (`agentd --socket-fd`, `agentd-supervisor`); preserves the private Unix transport and daemon ownership model of ADR-002 and ADR-003.

A trusted local supervisor may bind and retain the daemon's private `agentd.sock` Unix stream listener, then pass its inherited descriptor to `agentd --socket-fd N` on every start. The daemon duplicates the descriptor, validates its type, listening state, configured path and private ownership, and never unlinks that path. The supervisor owns the listener and its lifecycle. The daemon still obtains its exclusive database lock and performs conservative recovery before serving. The default without `--socket-fd` remains daemon-owned binding and refuses any existing path. No service is installed or enabled by this change.

This permits restart after SIGKILL without deleting a stale path when a trusted supervisor retains the listener. It does not create a supervisor, isolate same-user workers from operator credentials, or replay unacknowledged network requests. A restart loop, socket permissions, and lifecycle policy must be configured by an operator. The supervisor and user-private state directory are trust boundaries: a same-user process capable of replacing the pathname or passing a forged descriptor is not isolated by these checks. Existing clients must retry idempotent commands with their original keys. Systemd socket activation can supply one inherited descriptor as fd 3 when configured by an operator, but no unit files are deployed here.

The optional `agentd-supervisor` process implements this role locally: it owns the socket and one daemon child, restarts nonzero exits with bounded exponential backoff, and terminates the child on shutdown. It does not restart indefinitely, daemon state is recovered conservatively, and it does not install or enable a background service. A SIGKILL of the supervisor itself is outside this mechanism and can leave both a surviving child and an existing socket; operators must verify ownership before any cleanup or restart.
